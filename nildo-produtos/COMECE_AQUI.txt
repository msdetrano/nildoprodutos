NILDO — SITE + WEBAPP INSTALÁVEL
================================

1. Descompacte esta pasta.
2. Crie um repositório VAZIO no GitHub com o nome: nildo-produtos
   https://github.com/new
3. Na pasta do projeto, rode os comandos Git exibidos no README.md.
4. Na Vercel, importe o repositório. Framework: Other.
5. Crie um Redis Upstash e adicione as variáveis REST na Vercel.
   Adicione também ADMIN_PASSWORD e SESSION_SECRET (32 caracteres ou mais).
6. Faça deploy e acesse: https://nildoprodutos.vercel.app/gestao
   (dependendo da disponibilidade do endereço no seu projeto Vercel).
7. Confirme o WhatsApp pré-configurado (+55 14 99643-7437), edite os preços e publique.
8. O botão flutuante ENVIAR PEDIDO mostra a quantidade e abre o carrinho para revisão.

IMPORTANTE: nenhum pagamento acontece pelo site. O botão abre o WhatsApp
com o pedido completo e o cliente confirma o envio por lá.

Para testar no computador: Node.js 20+; copie .env.example para .env,
preencha a senha e o segredo e execute npm run dev.

Leia o README.md para todos os detalhes e cuidados de segurança.
